# Admin Panel (RAGE MP)

Программа для админов: полный список команд сервера по уровням, бинды на любые клавиши и счётчик репортов.

## Запуск (Windows)
1. Установите Python 3.10+ с python.org (галочка "Add to PATH").
2. Запустите `run.bat` - он сам поставит нужные библиотеки и откроет программу.
3. Чтобы получить один файл `AdminPanel.exe`, запустите `build.bat`. Готовый файл будет в папке `dist`.

**Запускайте от имени администратора.** Иначе Windows не даст программе перехватывать клавиши и вводить текст в игру.

## Как работают бинды
- Вкладка "Команды": нажмите на плитку, затем нажмите нужную клавишу или сочетание (например, Ctrl+W). Esc - убрать бинд у выбранной команды.
- По бинду программа нажимает клавишу чата, печатает команду (например `/mute `) и **не жмёт Enter**. ID, срок и причину админ дописывает сам.
- Значок корзины рядом с назначенной клавишей сбрасывает бинд, после этого можно нажать на плитку и назначить другой.
- Правый клик по плитке: в избранное, сбросить бинд, удалить (для своих команд).
- Если сочетание уже занято, программа спросит, заменить ли его.
- Показать или скрыть панель: Insert (меняется в настройках). Окно также открывается из значка в трее.

## Репорты
Вкладка "Репорты": счётчик за сегодня и за неделю (неделя с понедельника).
- Кнопка или бинд `+1 репорт` добавляет репорт.
- Кнопка или бинд `-1 репорт` убирает последний (если нажали случайно).
- Любой репорт из списка можно убрать кнопкой "Убрать выбранный".
- При нажатии бинда в игре внизу справа на секунду появляется подсказка с новыми цифрами.

## Оформление
Минималистичный чёрный интерфейс: фон `#000000`, рамки 1px `#1c1c1c`, единственный акцент - кремовый `#fae4c8`. Цвета и отступы собраны в константах `C_*`, `GAP`, `PAD` в начале раздела Theme файла `admin_panel.py`. Шрифт: Inter или Geist, если установлены, иначе Segoe UI.

## Уровень админки и консоль
При первом запуске программа показывает кружки с цифрами 1-10, нажатие на кружок выбирает ваш уровень администратора (команды выше уровня скрываются). Потом спросить его в настройках нельзя: уровень повышается только командой `/aupgrade <уровень>` на вкладке "Консоль". Другие команды консоли: `/alevel` (показать уровень), `/clear`.

Вкладка "Список команд" показывает все команды, доступные на вашем уровне: на уровне 1 только первого уровня, на уровне 2 первого и второго и так далее.

Это защита от случайной ошибки, а не от взлома: уровень хранится в `config.json` на компьютере и его можно поправить вручную. Настоящую проверку прав делает сервер.

## Настройки
Язык (English по умолчанию, Русский, Українська), переключатель "Открывать чат автоматически" (если выключить, бинд только впечатывает команду в уже открытый чат, клавиша чата не нажимается), клавиша чата в игре (по умолчанию `t`), задержки, прозрачность окна, автозапуск с Windows, импорт и экспорт биндов, добавление своих команд.

Данные хранятся в `%APPDATA%\AdminPanel\config.json`.

## Что важно знать
- История показывает команды, которые бинды ввели в игру. Что админ дописал дальше (ID, причину) и нажал ли Enter, программа не видит.
- Бинды работают только на клавиатуру, кнопки мыши пока не поддерживаются.
- Если в вашей сборке чат открывается не клавишей `T`, поменяйте её в настройках.

## Сборка и установщик
- `build.bat` собирает `dist\AdminPanel.exe` (с запросом прав администратора при запуске).
- `build_installer.bat` собирает exe и установщик `installer_output\AdminPanel-Setup.exe`. Нужен [Inno Setup 6](https://jrsoftware.org/isdl.php).

## Публикация на GitHub
1. Создайте на github.com пустой репозиторий (без README) и загрузите в него всё содержимое этой папки, включая скрытую папку `.github`:

```
git init
git add .
git commit -m "Admin Panel"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/AdminPanel.git
git push -u origin main
```

2. Выпуск версии: на странице репозитория Releases -> Draft a new release, в поле Tag введите `v1.0.0` (Create new tag), нажмите Publish release.
3. GitHub Actions (`.github/workflows/release.yml`) сам соберёт `AdminPanel.exe` и установщик и прикрепит `AdminPanel-Setup.exe` к этому релизу. Сборка занимает несколько минут, ход виден на вкладке Actions.

Ссылка для скачивания: `https://github.com/ВАШ_ЛОГИН/AdminPanel/releases/latest`.

Если в Settings -> Actions -> General у репозитория выключена запись для workflow, включите Read and write permissions.
