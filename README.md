# Admin Panel — C# port (initial migration)

Проект перенесён на C# / .NET 10 Windows Forms. Список из 244 стандартных команд исходной версии сохранён в `AdminPanel/commands.json`.

## Сборка приложения
1. Установить .NET 10 SDK на компьютере разработчика.
2. Запустить `build.ps1` в PowerShell.
3. В папке `publish` появится приложение.

## Сборка установщика
1. Установить Inno Setup 6.
2. Открыть `Installer/AdminPanel.iss`.
3. Нажать Compile. Результат — `dist/AdminPanel-Setup.exe`.

Установщик проверяет наличие **.NET 10 Desktop Runtime x64**. Если runtime отсутствует, он скачивает официальный установщик с `aka.ms` и запускает его в тихом режиме до копирования файлов приложения. Для скачивания требуется интернет.

## Важно о текущем переносе
Это первая рабочая основа переноса, а не побитовая копия всех функций Python-версии. Перенесены структура приложения, тёмная оболочка, каталог команд, конфигурация, избранное, назначение клавиши, базовые настройки, заметки и счётчик репортов. Расширенные элементы оригинала (полный набор глобальных биндов, обновлятор, анимации/плитки, звуковые эффекты и точное поведение всех экранов) требуют отдельной итерации и тестирования на Windows.


## Автоматическая сборка через GitHub Actions

После загрузки проекта в ветку `main` GitHub Actions сам:
- установит .NET 10 SDK и Inno Setup;
- соберёт приложение;
- скомпилирует `AdminPanel-Setup.exe`;
- прикрепит установщик к запуску workflow как Artifact.

Где скачать результат: репозиторий → **Actions** → последний успешный запуск **Build Windows installer** → блок **Artifacts** → `AdminPanel-Setup`.

Чтобы дополнительно создать GitHub Release с установщиком, создай и отправь тег версии, например:
`git tag v1.2.0`
`git push origin v1.2.0`


### Исправление окна назначения биндов

Окно назначения клавиши реализовано как полноэкранная панель поверх интерфейса главного окна. Оно не создаёт отдельный Form, не имеет собственной рамки и не может перемещаться независимо от приложения. Карточка назначения отображается по центру приложения; клавиша Esc или кнопка «Отмена» закрывает её.
